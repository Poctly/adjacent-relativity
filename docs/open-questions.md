## Structural questions

- When is a repeated name an individual, a ritual embodiment, an epithet, or a recurring role?
- Which accounts themselves distinguish cosmic and heroic manifestations?
- When does cyclicity clarify a relation, and when does it obscure a genuine difference?
- How do initial establishment, restoration, and recurrence differ in each narrative?
- Can an adjacent comparison predict a detail not used in constructing it?
- What observation would require abandoning the cycle-based interpretation?
- How should comparable structures be distinguished from common narrative conventions?
